## 🌐 Overview

**VayuX Systems** is an innovation-driven cybersecurity research and development firm headquartered in **Vadodara, Gujarat, India**. We reject conventional, reactive maintenance. Instead, VayuX operates as a dynamic laboratory where low-level engineering research channels directly into self-defending, autonomous digital infrastructure.

Every real-world security engagement—**Managed SOC Operations**, **Vulnerability Assessment & Penetration Testing (VAPT)**, **Digital Forensics & Incident Response (DFIR)**, and **Governance, Risk & Compliance (GRC)**—feeds operational telemetry into our R&D core to engineer next-generation defensive architectures.

## ✨ Key Architectural Features

### 1. 🌍 Interactive 3D Telemetry Globe (`react-globe.gl` & WebGL)
- **Central Command Spotlight**: Primary headquarters pinned at **Vadodara, India** (`22.3072° N, 73.1812° E`) with pulsating golden radar arrays.
- **Adaptive Day/Night Shaders**: Automatically renders high-resolution NASA Blue Marble daylight topology in Light Mode and deep obsidian Earth-Night emission shaders in Dark Mode.
- **Interactive Controls**: Features drag-to-rotate, auto-rotation toggling, dedicated **Vadodara HQ Focus**, and customizable zoom bounds with a bounded lower cap.
- **Live Transmission Arcs**: Real-time laser arcs connecting Vadodara to 14 global operating nodes (London, Tokyo, San Francisco, Dubai, Reykjavik, Singapore, etc.).

### 2. 🦅 Aetheric Sentinel Hero Visual
- **Suspended Studio Fixture**: Continuous ambient pendulum swaying physics with realistic downward spotlight cones.
- **Interactive Parallax**: Multi-layer metallic eagle emblem reacting to cursor coordinates and gyroscope input.
- **Emissive Laser Core**: Pulsating ocular telemetry beam with synchronized breathing contact shadows.

### 3. 🌗 Dual-Engine Obsidian & Celestial Design System
- **Celestial Light Mode**: Crystalline porcelain surfaces, tailored cyan-blue atmospheric gradients (`#006399` → `#00a8ff`), and high-clarity typography.
- **Obsidian Dark Mode**: Deep black space (`#050505` / `#09090b`), translucent cyber glass (`rgba(7, 11, 22, 0.9)`), glowing neon borders, and zero cloudy artifacts.
- **Zero-Hydration-Mismatch Theming**: Inline pre-hydration script ensuring immediate theme application with zero screen flashes.

### 4. ⚡ Ambient Palo Alto-Style Cyber Matrix Background
- Mounted globally with subtle telemetry grid crosshairs, dynamic scanlines, floating hex node tags (`NODE_ARRAY // EUR-WEST-1`, `HEURISTIC_PIPELINE: ACTIVE`), and radiant diffuse glow orbs.

### 5. 🧭 Smart Directional Navigation
- Header intelligently auto-hides when scrolling down on desktop/laptop views to eliminate screen clutter and smoothly glides back into view when scrolling up or near the page crest.

## 🚀 Quick Start

### Prerequisites
- **Node.js**: `v18.18.0` or higher (Node.js 20+ recommended)
- **Package Manager**: `npm`, `pnpm`, or `bun`

### 1. Clone the repository
```bash
git clone https://github.com/yasuo72/Vayux_landing.git
cd Vayux_landing/vayux-v2
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start the local development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to explore the platform.

### 4. Build for production
```bash
npm run build
npm run start
```
*The build automatically prerenders and verifies all 34 static routes.*

## 🤖 SEO, GEO & LLM Intelligence

VayuX v2 is engineered from the ground up for search engine dominance and AI search engines (ChatGPT Search, Perplexity, Google Gemini):

- **LLM Context File (`public/llms.txt`)**: Specially formatted machine-readable summary allowing AI crawlers to accurately cite VayuX's capabilities.
- **Dynamic Semantic Sitemap (`src/app/sitemap.ts`)**: Auto-indexing all static routes, solutions, legal vaults, and glossary terms.
- **Comprehensive JSON-LD Schemas (`src/lib/seo-config.ts`)**: Full schema graph including `Organization`, `CybersecurityService`, `WebSite`, and `BreadcrumbList`.
- **Programmatic Glossary (`src/app/glossary/`)**: 15+ rich terminology pages targeting long-tail enterprise cybersecurity search queries.
